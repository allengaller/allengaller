### 👋 About

I build at the intersection of **Cloud Native**, **AI Tooling**, and **Knowledge Architecture** — turning production experience into reusable tools, compounding knowledge bases, and a long-run personal brand. My knowledge bases are written to be read twice: once by humans, once by agents (as RAG corpora).

我在 Cloud Native、AI 工具链与知识架构的交叉地带持续输出：把生产经验沉淀成可复用工具、可增长的知识资产和可长期经营的个人品牌。我的知识库按"人读手册 + Agent RAG 语料"双读标准写作。
